这个网站是怎么搭建的 🛠️

📖 约 5 分钟 · #建站 #前端 #GitHub Pages

你现在看到的这个网站,没有用任何框架,也没有数据库和服务器, 只有三个文件:index.html、style.css、script.js, 托管在 GitHub Pages 上,完全免费。这篇文章记录一下搭建思路。

为什么不用框架

React、Vue 当然强大,但对一个以「内容」为主的个人网站来说,它们能带来的收益很有限:

  • 页面基本是静态的,不需要复杂的状态管理;
  • 不用构建工具,改完保存刷新就能看到效果,调试成本几乎为零;
  • 三个文件就是全部源码,十年后打开依然能跑,不怕依赖升级。

当然,如果以后要写大量文章,我可能会迁移到 Jekyll 或 Hexo 这类静态站点生成器—— 但那是「内容多到管理不过来」之后的事。

深色模式:四个 CSS 变量就够

整站的深浅色切换,核心思路是把所有颜色收进 CSS 变量,再通过 data-theme 属性整体切换:

:root {
  --bg: #f6f8fc;        /* 页面背景 */
  --surface: #ffffff;   /* 卡片背景 */
  --text: #101828;      /* 正文颜色 */
  --border: #e4e9f2;    /* 描边 */
}

html[data-theme="dark"] {
  --bg: #0b1020;
  --surface: #141b31;
  --text: #e9edf8;
  --border: #242e4d;
}

切换按钮只需要一行 JS:改一下 data-theme,再把偏好存进 localStorage, 下次访问就还是用户选的主题了。

部署到 GitHub Pages

部署过程简单到不好意思写教程,但为了完整还是记一下:

  1. 在 GitHub 创建一个名为 用户名.github.io 的仓库;
  2. 把网站文件推上去:
git init
git add .
git commit -m "init: 个人网站"
git remote add origin https://github.com/用户名/用户名.github.io.git
git push -u origin main
  1. 等一两分钟,访问 https://用户名.github.io,网站就上线了 🎉

之后每次 git push,线上都会自动更新。

踩过的坑

  • 锚点被固定导航挡住 —— 给 html 加 scroll-padding-top 即可;
  • 滚动浮现动画导致内容闪烁 —— 动画只做位移和透明度,并且用 IntersectionObserver 触发后立即解除监听;
  • 字体加载慢 —— 干脆不用 Web 字体,系统字体栈(PingFang SC / Microsoft YaHei)效果就很好,还省了一次网络请求。
