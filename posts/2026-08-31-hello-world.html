📖 约 4 分钟 · #随笔 #建站

这是这个博客的第一篇文章。在一切开始之前,先回答一个被问过很多次的问题: 都 2026 年了,社交平台这么发达,为什么还要自己搭一个博客?

为什么要写博客

社交平台上的内容是「流」——发出去,被刷过,就沉下去了。而博客更像一座「小花园」: 每篇文章都种在那里,可以被搜索、被引用,两年后翻回来还能继续浇灌。

更重要的是,写作本身就是思考。很多时候我以为自己懂了,直到开始下笔才发现逻辑里全是窟窿。 把一件事写清楚,是检验是否真正理解的最好方式。

「Writing is thinking. 如果写不清楚,说明还没想清楚。」

这里会写些什么

  • 学习笔记 —— 新技术、新工具的入门记录与踩坑总结;
  • 项目复盘 —— 做过的项目,哪些决策是对的,哪些想重来;
  • 生活随笔 —— 读书、摄影、跑步,以及一些无用的思考。

如何发布一篇文章

这个博客没有任何后台,写文章就是往 posts/ 目录里加一个 HTML 文件,步骤一共四步:

  1. 复制 posts/template.html,把文件名改成 日期-英文标题.html,例如 2026-09-15-my-new-post.html;
  2. 打开文件,修改 <title>、大标题和正文(模板里有注释标好了位置);
  3. 在 blog.html 的文章列表里加一条链接;
  4. 提交并推送,一分钟后线上就能看到:
git add .
git commit -m "发布新文章:我的新文章"
git push

最后

不给自己定「周更」之类的 flag,只希望这里能一直有「写完之后觉得没白写」的文章。 如果某篇文章恰好帮到了你,欢迎通过首页的联系方式告诉我,那会让我很高兴 🙂
